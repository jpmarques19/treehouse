# Step 11: Create Context.yaml

## STEP GOAL:

Create the context.yaml file in the base workspace's tracking folder to establish lineage tracking for the new nook.

## MANDATORY EXECUTION RULES (READ FIRST):

### Universal Rules:

- 📖 CRITICAL: Read the complete step file before taking any action
- 🎯 Write to BASE workspace tracking folder, not nook
- ✅ Include full lineage chain

### Role Reinforcement:

- ✅ You are a workspace automation assistant
- ✅ Build complete lineage from existing context
- ✅ Include all relevant metadata

## EXECUTION SEQUENCE:

### 1. Create Tracking Directory

```bash
mkdir -p "{{base_path}}/.bmad-tracking/{{new_branch}}"
```

### 2. Build Lineage Chain

<action>Start with existing lineage (if any):</action>
- If {{existing_lineage}} is not empty: Use as base
- If {{existing_lineage}} is empty: Start new chain

<action>Add current entry to lineage:</action>
```yaml
- branch: {{new_branch}}
  type: {{nook_type}}
  parent: {{current_branch}}
  hash: {{parent_hash}}
  date: [current ISO date]
```

### 3. Create Context.yaml

<action>Write context.yaml to tracking folder:</action>

```yaml
# Nook Context - Auto-generated by nook-fork
# Do not edit manually - use nook-sync to update

branch:
  name: {{new_branch}}
  type: {{nook_type}}
  forked_from: {{current_branch}}
  created_date: [current ISO date]
  created_by: [user from config or system]

parent:
  branch: {{current_branch}}
  hash: {{parent_hash}}

lineage:
  # Full chain from base to this nook
  {{full_lineage_yaml}}

artifacts:
  # Sync status - all false for new nook
  docs_synced: false
  context_synced: false
  last_sync: null

agent:
  created: {{agent_mode != 'none'}}
  name: {{custom_agent}}
  mode: {{agent_mode}}

notes: |
  Next steps:
  - cd {{worktree_path}}
  - Restore docs if needed: /th:workflows:nook-restore
  - Activate agent (if created): /bmad:custom:agents:{{custom_agent}}
  - When done: /th:workflows:nook-sync to save context
```

<action>Write file:</action>
```bash
# Write to base workspace tracking folder
cat > "{{base_path}}/.bmad-tracking/{{new_branch}}/context.yaml" << 'EOF'
[content from above]
EOF
```

### 4. Verify File Created

```bash
test -f "{{base_path}}/.bmad-tracking/{{new_branch}}/context.yaml" && echo "SUCCESS" || echo "FAILED"
```
